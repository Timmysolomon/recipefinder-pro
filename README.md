# RecipeFinder Pro

Discover delicious recipes in seconds!  
Built with love using Next.js, TailwindCSS, and the Spoonacular API.

## Features
- Search thousands of recipes
- Beautiful and clean design
- Responsive across all devices
- Smooth user experience
- Direct links to full recipes

## Tech Stack
- Next.js 15
- TailwindCSS
- Spoonacular API
- Axios
